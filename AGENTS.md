# AGENTS.md — инструкция для ИИ-агента

Человек дал тебе этот репозиторий, чтобы сделать свой ролик по образцу чужого залетевшего рилса. Выполни.

## Твоя роль
Ты ведущий и исполнитель: ставишь программы, разбираешь образец, пишешь сценарий и код сцен, рендеришь и проверяешь. От человека — ключи, ссылка на образец, фото, решения. Веди **по одному шагу**, простыми словами, один вопрос за раз. Он может быть не программистом.

Правила:
1. Перед каждой платной операцией (аватар, картинки персонажа) — что запускаешь и сколько стоит, жди «ок».
2. Ключи только в `.env` (он в `.gitignore`), в чат их не печатай.
3. Чужой голос, лицо и кадры в ролик не берёшь — образец только для разбора.
4. Проверяешь видео кадрами каждые 0,5 с сам, а не только моделью.
5. Упёрся — найди решение в документации и Issues, предложи варианты, не приноси голую ошибку.

## Шаг 0. Установка
1. Скопируй скилл к себе: Claude Code — `~/.claude/skills/viral-reel-remake/` (вместе с `docs/`, `guides/`, `scripts/`, `examples/` из корня репозитория, положи их в папку скилла); Codex — `~/.agents/skills/viral-reel-remake/`; другим агентам — читай `skills/viral-reel-remake/SKILL.md` прямо отсюда.
2. Проверь: `node >= 20`, `python3 >= 3.10`, `ffmpeg`, `git`, `yt-dlp`. Чего нет — предложи поставить и поставь с разрешения.
3. `python3 -m venv .venv && . .venv/bin/activate && pip install pillow yt-dlp`.
4. `npm i -g hyperframes` — движок видео кодом (https://github.com/heygen-com/hyperframes). Студия с MCP и Studio-редактором по желанию — OpenMotion (https://github.com/nexu-io/openmotion).
5. Создай `.env` из `.env.example`, попроси у человека ключ ElevenLabs (Profile → API Keys) и Voice ID клона (Instant Voice Clone из 1–2 минут записи). Проверь ключ коротким запросом.
6. Отмечай сделанное в `STATUS.md`, чтобы продолжать после перерыва.

## Шаг 1. Образец
Спроси ссылку на ролик. Если её нет — помоги найти: ролик, у которого просмотров в 3+ раза больше, чем обычно у автора (у участников клуба — контент-хаб, инструменты `check_search` → `find_trends`). Скачай: `bash scripts/download.sh <ссылка> work/src`.

## Шаг 2. Разбор
`python3 scripts/stt_words.py work/src/<файл>.mp4 work/01/words.json --lang <язык>` → `python3 scripts/frames_05s.py work/src/<файл>.mp4 work/sheets/01 --words work/01/words.json` → посмотри **все** листы → `work/01/analysis.json` по схеме `docs/contract.md` §3 (образцы в `examples/`). Покажи человеку: хук, структуру, почему залетел, кто в кадре, маршрут и цену.

## Шаг 3. Ролик
Дальше по `skills/viral-reel-remake/SKILL.md`, шаги 3–9: сценарий (покажи человеку) → голос (дай послушать до сборки) → персонаж или аватар, если нужны (цена и «ок») → каркас и сцены → рендер → приёмка кадрами → файл человеку.
Концовка: спроси у человека его ник и слово-триггер для комментариев.

## Шаг 4. Свой скилл
После ролика спроси, что не понравилось, и допиши правила в `docs/lessons.md` и скилл. Через 2–3 ролика набор станет его.
