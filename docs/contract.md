# Контракт: залетевший ролик → JSON → ваш ролик под ключ

Один контракт на ролик или на всю серию. Если роликов несколько — задание на каждый строкой в `work/VIDEOS.md`.
Рабочая папка: `work/` (образцы в `work/src/`, листы кадров в `work/sheets/`, всё по ролику в `work/NN_<автор>/`).

## 0. Правила
- Голос только ваш: клон ElevenLabs (`eleven_v4_turbo`, `/with-timestamps`, словарь произношения). Чужой голос в ролик не идёт.
- Без фоновой музыки, громкость итогового MP4 −14 LUFS. Музыку ставите при публикации в самой соцсети.
- Длина ±15 % от оригинала.
- Проверка видео: кадр каждые 0,5 с со словами речи (`scripts/frames_05s.py --words`), смотреть все листы; модель (Gemini) — вторая линия.
- Перед каждой платной генерацией (лицо, картинки) агент называет цену и ждёт «ок».
- Ключи — только в `.env`, в чат и в git не попадают.

## 1. Что берём из оригинала, а что делаем сами
- **Хук (первая фраза, 2–4 с)** — слово в слово. Русский оригинал — тот же текст; английский — точный перевод на живой русский без пересказа.
- **Всё остальное** — та же структура, тот же порядок шагов, тот же ритм смен кадра (±0,5 с) и тот же стиль (палитра, шрифты, раскладка кадра, переходы, подсветка слов), но своими словами и про ваш опыт.
- **Экраны и интерфейсы** пересобираются кодом (HyperFrames / OpenMotion). Кадры оригинала — только образец, в ролик не идут.
- **Голос и лицо чужого автора** в ролик не идут. Только ваш голос, ваше лицо (аватар) или нарисованный вы.
- **Финал (CTA):** ваш призыв, например «Подписывайся на меня» + ваш ник на экране + «напиши в комментариях слово». Карточку профиля автора заменить на вашу, без выдуманных цифр подписчиков.

## 2. Типы кадра (фиксировать в JSON для каждого сегмента)
| `shot_type` | Что в кадре | Чем делаем |
|---|---|---|
| `person_live` | живой человек (лицо, тело) | ваш аватар: Omni ([omni-video-kit](https://github.com/PavelDumbrao/omni-video-kit)) или kie.ai ([ai-video-lesson-kit](https://github.com/PavelDumbrao/ai-video-lesson-kit)); готовый клип вставляется в сборку |
| `person_partial` | видна только часть человека (рука, палец), лица нет | пересобрать без человека: экран кодом + курсор или подсветка |
| `animated_character` | нарисованный / 3D-персонаж автора | вы в том же стиле: Nano Banana по вашему фото → правки ртов и поз → перекладка с липсинком по буквам |
| `motion_only` | только графика, текст, интерфейсы | HyperFrames / OpenMotion |
| `screen_capture` | запись или съёмка экрана | экран кодом с вашими данными; «съёмку телефоном» имитировать перспективой, дрожанием, бликами |
| `split` | кадр поделён: графика сверху + человек/персонаж снизу | две зоны отдельно, пропорция как в оригинале |

## 3. Схема `analysis.json` (одна на ролик)
```json
{
  "source": {"url": "", "author": "", "views": 0, "outlier_x": 0, "duration_s": 0, "language": "en|ru", "size": "540x960"},
  "people": {"has_live_person": false, "has_partial_person": false, "has_animated_character": false, "notes": ""},
  "format": {"layout": "full|split_top_graphics_bottom_person|...", "split_ratio": "55/45", "captions": "стиль титров: место, шрифт, подсветка слова", "palette": ["#..."], "fonts": "", "transitions": "", "pace": "смен кадра в минуту"},
  "transcript": [{"start": 0.0, "end": 0.4, "text": ""}],
  "hook": {"start": 0.0, "end": 3.0, "original_text": "", "ru_text": "", "why_it_hooks": ""},
  "segments": [
    {"start": 0.0, "end": 3.0, "shot_type": "motion_only", "on_screen": "что видно по кадрам 0,5 с", "text_on_screen": "", "speech": "", "camera": "наезд/статично/...", "purpose": "хук|шаг N|доказательство|CTA"}
  ],
  "structure": ["хук", "шаг 1", "..."],
  "why_viral": ["конкретные причины, с секундами"],
  "cta": {"type": "comment_keyword|follow|link", "original_text": "", "our_text": ""},
  "remake_plan": {"route": "motion|motion+avatar|motion+character", "segments_map": "какой сегмент чем делаем", "est_cost_rub": 0}
}
```
Сегменты резать по реальным сменам кадра на листах 0,5 с, а не по ровной сетке. Готовые образцы — `examples/*/analysis.json`.

## 4. Порядок работы
1. Скачать образец (`scripts/download.sh`), вынуть звук.
2. Речь → слова (`scripts/stt_words.py --lang en|ru`) → листы кадров 0,5 с со словами (`scripts/frames_05s.py --words`) → посмотреть **все** листы → `analysis.json`.
3. Сценарий: `display_script.md` (что на экране, латиница как есть) и `spoken_script.md` (что звучит). Хук слово в слово. Текст шагов на ~10 % короче оригинала по знакам.
4. Голос с таймингами слов, 2–3 дубля, проверка ударений; при длине больше +15 % — `atempo 1.05–1.08`.
5. Люди / персонаж: сгенерировать сегменты, проверить губы и лицо кадрами 0,5 с.
6. Сборка (9:16, 1080×1920, 30 к/с), титры по словам вашего голоса в стиле оригинала. Рендер, −14 LUFS.
7. Приёмка: листы 0,5 с всего ролика + Gemini (видео со звуком) + расшифровка готового ролика против сценария. Брак — исправить и проверить снова.

## 5. Что получается в папке ролика
`analysis.json`, `display_script.md`, `spoken_script.md`, итоговый `NN_<автор>.mp4`, `REPORT.md` (что сделано, сколько стоило, что проверено), `lessons.md` (грабли — переносите их в скилл, и он станет вашим).
