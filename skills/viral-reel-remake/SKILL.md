# Ремейк залетевшего ролика: видео → JSON → ваш ролик

Проверено на 9 роликах (ноябрь 2026): от 30 с до 1,5 минут, ~10–30 ₽ на ролик без аватара, рендер бесплатный.
Перед стартом прочитай `docs/contract.md` (правила и схема JSON) и `docs/lessons.md` (грабли). Инструменты и ссылки — `guides/tools.md`.

## Правила
- **Хук слово в слово** (английский — точный перевод). Остальное — та же структура, ритм и стиль, но своими словами про опыт человека.
- **Чужой голос, лицо и кадры в ролик не идут.** Экраны пересобираются кодом; лицо — аватар человека или нарисованный он.
- Голос — клон человека в ElevenLabs. Без музыки, −14 LUFS, длина ±15 % от оригинала.
- Перед платной генерацией — цена и «ок» человека.

## Workflow
1. **Образец**: `bash scripts/download.sh <ссылка> work/src` (Instagram — с куками браузера). Найти залетевший ролик помогает контент-хаб клуба (`check_search` → `find_trends`).
2. **Разбор → `analysis.json`**: `python3 scripts/stt_words.py <видео> work/NN/words.json --lang en` → `python3 scripts/frames_05s.py <видео> work/sheets/NN --words work/NN/words.json` → посмотреть **все** листы → JSON по схеме `docs/contract.md` §3 (образцы в `examples/`).
3. **Маршрут** по типу кадра (`docs/contract.md` §2): графика и экраны — HyperFrames/OpenMotion; нарисованный персонаж — Nano Banana + перекладка; живой человек — аватар (Omni или kie.ai), в сборку идёт готовый клип; поделённый кадр — две зоны отдельно.
4. **Сценарий**: `spoken_script.md` + `display_script.md`, хук дословно, текст шагов на ~10 % короче оригинала.
5. **Голос**: 2–3 дубля с таймингами, проверка ударений; длина в ±15 % → `atempo`.
6. **Каркас**: сборщик сцен по словам-якорям голоса, общий css, титры, корень, тестовая сборка. Потом сцены (саб-агентами, если есть, не больше 2 параллельно на ноутбуке).
7. **Рендер**: `hyperframes render` (черновик для правок, чистовик в конце) → `loudnorm` −14 LUFS.
8. **Приёмка**: свои листы 0,5 с по всему ролику → Gemini со звуком → расшифровка готового ролика против сценария. Находки модели проверять измерением.
9. **Итог**: MP4, `REPORT.md`, `lessons.md`. Грабли, которые встретились, — дописать в `docs/lessons.md`: так скилл становится вашим.

## Только разбор (видео → JSON)
Шаги 1–2. Полезно, чтобы понять, почему ролик залетел: хук, ритм смен кадра, где доказательство, какой CTA.

## Smoke tests
- «Вот рилс, сделай такой же» → скачать, `analysis.json`, тип кадра, маршрут и цена до платных шагов.
- «Разбери ролик в JSON» → только разбор, без сборки.
- «Поменяй концовку» → отдельный кусок голоса + сцена CTA, склейка в тишине, старый файл в `_v1`.

## Red flags
- В ролике чужой голос, лицо, скриншот или ник автора.
- Приёмка только по вердикту модели, без своих листов 0,5 с.
- Новый голос под старым именем файла.
- Ключи в чате или в git.
