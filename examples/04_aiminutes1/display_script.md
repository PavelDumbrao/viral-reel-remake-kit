# Ролик 04 — экранный сценарий (display)

1080×1920, 30 к/с, ~55,4 с. Стиль 1:1 с оригиналом: бежевый тёплый фон (радиальный градиент), терракотовый акцент `#D8573F`,
тёмные окна приложений `#1C1918`, зелёные галочки `#3DD68C`, заголовок Inter 900 в два цвета, метка шага моно с разрядкой,
белая плашка-субтитр внизу (слова добавляются по одному, ключевые — терракотой), под ней ник «@paveldumbrao»,
контурный силуэт города внизу. Переходы между шагами — растворение с размытием 0,35 с. Музыки нет.
