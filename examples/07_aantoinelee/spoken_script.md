# 07 · spoken (текст для ElevenLabs, PVC, `eleven_v4_turbo`, словарь `pavel-hard-words-ru`)

Латиница из словаря (Claude Code, MCP, Obsidian, Codex, UI, VPS, Telegram) остаётся латиницей; вне словаря — русская фонетика: «Плейрайт», «Нано Банане», «Клингу», «ПРО».
Хук — точный перевод оригинала («If you use Claude Code like this, but you keep seeing other people run this, these are the seven tools I use around Claude Code every single day»).

```text
Если ты пользуешься Claude Code вот так, а у других постоянно видишь вот такое, — вот семь инструментов, которые я каждый день использую вместе с Claude Code.
На этой связке я веду уже шестой поток Хардкодинг ПРО, а агенты пишут код за меня каждый день.
Номер один — параллельные сессии Claude Code. Несколько агентов рядом, у каждого своя задача, а тот, кто ждёт моего ответа, сразу подсвечен.
Второй — Obsidian как второй мозг. Агенты сами читают и пишут в него через MCP. Самое важное — у всех агентов во всех проектах один общий контекст.
Третий — Плейрайт MCP. По сути, это глаза для агента: он сам открывает сайт, прокликивает его и проверяет, что всё работает как надо.
Номер четыре — обязательно второй агент на ревью. Codex проверяет каждую правку Claude против всего проекта.
Номер пять — дизайн-скиллы. Claude берёт приёмы лучших интерфейсов, видит, что у них работает, и переносит это в твой UI.
Номер шесть — если не хочешь, чтобы сайт выглядел шаблонно, делай свою графику. Подключи Claude к Нано Банане или к Клингу.
И номер семь — запускай агентов в облаке, потому что всё, что выше, требует открытого ноутбука. Claude Code спокойно работает без экрана на твоём VPS, а пишешь ты ему прямо в Telegram. Советую это для любой задачи, которую гоняешь регулярно.
Как настроить каждый — разберу в следующих роликах, так что подписывайся на меня. И напиши в комментариях «ИИ», если хочешь полный гайд.
```
